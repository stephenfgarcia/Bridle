# Bridle

- Start with [README.md](README.md) ("Start here"): the plan is `docs/plan/roadmap.md`, the progress and the latest pause entry are in
  `docs/plan/progress.md`, the owner's decisions are in `docs/decisions/log.md`.
- Work runs as factory cards (`factory/README.md`, `.claude/skills/factory/SKILL.md`); a parked card says how to resume in the pause note
  at the end of its Spec.
- Several sessions may share this checkout: re-read a file before editing it, stage only your own files by explicit path (never
  `git add -A`), announce commits to the other sessions, and let only one session run the monitor watch.
