# P0-02.1 Workspace skeleton and the first pnpm check

## Spec

What: the monorepo skeleton the architecture names (section 16) with one real crate and one real package, and the first `pnpm check`.
Acceptance criteria:
1. Root files: `package.json` (`"packageManager": "pnpm@12.16.1"`, `"engines": {"node": "22"}`, scripts `check`, `test`, `lint`, `typecheck`, `fmt`), `pnpm-workspace.yaml` (`apps/*`, `packages/*`), `turbo.json` (turbo >= 2.11.10, tasks lint, typecheck, test, build with correct `dependsOn`), `Cargo.toml` workspace (`members = ["crates/*"]`, resolver 2, shared `[workspace.package]` edition 2021 and rust-version from tools/toolchain.json), `.editorconfig`, `.gitattributes` (LF), `rustfmt.toml`, `clippy.toml` or `[workspace.lints]` with `clippy::all` as warn-as-error in CI.
2. `crates/bridle-canon`: a library crate with one documented function (e.g. `canon_version() -> &'static str` returning "canon/1") and one unit test; `packages/units`: a TypeScript library package (strict tsconfig, vitest) with one function (e.g. SI conversion of a length) and one test; both named exactly as in architecture.md section 16.
3. `pnpm check` runs, in order and failing fast: `pnpm lint` (biome or eslint+prettier, one choice documented), `pnpm typecheck` (tsc --noEmit per package via turbo), `pnpm test` (vitest), `cargo fmt --all --check`, `cargo clippy --workspace --all-targets -- -D warnings`, `cargo test --workspace`; it prints one line per step with its wall time and exits 0 on this machine in under 3 minutes (first run excluded).
4. `pnpm install --frozen-lockfile` works from a clean clone (lockfile committed); `bash tools/doctor.sh` still exits 0.
Out of scope: compose (P0-02.2), CI (P0-02.3), Dockerfile (P0-02.4), apps/web (P0-02.5), i18n (P0-02.6), any real schema or solver code.
Files: package.json, pnpm-workspace.yaml, pnpm-lock.yaml, turbo.json, Cargo.toml, Cargo.lock, rustfmt.toml, .editorconfig, .gitattributes, crates/bridle-canon/*, packages/units/*, tools/check.sh (if the check needs a script).
