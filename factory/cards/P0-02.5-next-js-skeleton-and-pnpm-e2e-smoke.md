# P0-02.5 Next.js skeleton and pnpm e2e:smoke

## Spec

What: the Next.js 15 application skeleton under apps/web and the Playwright smoke test the stations run.
Acceptance criteria:
1. `apps/web`: Next.js 15 with React 19 and the App Router, TypeScript strict, one route `/` rendering a page that says Bridle with the git sha and the educational-use notice (plain text), a `/api/v1/health` route handler returning `{ok: true, sha}`; `pnpm --filter web dev` serves it; `pnpm --filter web build` passes; lint and typecheck are part of `pnpm check`.
2. `pnpm e2e:smoke` starts the app (or uses the running dev server), runs Playwright Chromium (pinned 1.64.1) against `/` and `/api/v1/health`, saves a screenshot under `.bridle/screenshots/` (gitignored), and exits 0; the Playwright config lives at the root (`playwright.config.ts`) with the Chromium project only.
3. No design-system work (P4-06) and no shell; the page is deliberately plain.
4. `docs/ops/local-dev.md` gains the commands.
Files: apps/web/*, playwright.config.ts, e2e/smoke.spec.ts, package.json scripts, docs/ops/local-dev.md.
