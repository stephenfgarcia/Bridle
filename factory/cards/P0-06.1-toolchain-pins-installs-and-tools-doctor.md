# P0-06.1 Toolchain pins, installs, and tools/doctor.sh

## Spec

What: pin the toolchain in one place and install it on this machine; a doctor script that proves it.
Why: every later card (Rust core, wasm builds, pnpm workspace, compose, OpenTofu) assumes these tools at pinned versions; P0-02's first test is this doctor.

Acceptance criteria:
1. `tools/toolchain.json` is the single source of pins: rust channel (a specific stable, e.g. 1.9x.y), node major 22, pnpm version, wasm-bindgen-cli version, binaryen (wasm-opt) major, wasmtime CLI major, OpenTofu minimum, AWS CLI v2, Playwright version, docker engine present; `rust-toolchain.toml` (channel from the pins, `targets = ["wasm32-unknown-unknown"]`, components rustfmt and clippy) and `.node-version` (22) are generated from or kept consistent with it (a check in doctor.sh fails on drift).
2. Installed and on PATH after the card ships (installs are allowed: rustup-init for Rust, `nvm install 22` for Node 22 (nvm is present), corepack to pin pnpm, Homebrew for binaryen, wasmtime, opentofu, awscli, and OrbStack or Docker Desktop (cask; may need the user's password), `cargo install wasm-bindgen-cli --version <pin>`, `npx playwright@<pin> install chromium`): rustup/cargo at the pinned channel with the wasm32 target, wasm-bindgen, wasm-opt, wasmtime, node 22 and pnpm at the pins, tofu, aws, docker running (`docker info` succeeds), Playwright Chromium.
3. `tools/doctor.sh` checks every pin, prints one row per tool (name, want, have, ok/MISSING/MISMATCH), exits 0 only when all pass, exits 1 naming each failure; runs in under 5 s; works with `bash tools/doctor.sh` from any directory.
4. `docs/ops/toolchain.md` lists the install commands per tool for a new machine (what the card ran).
Out of scope: package.json or any workspace file (P0-02), CI (P0-02.3), Dockerfile (P0-02.4).
Files likely touched: tools/toolchain.json, rust-toolchain.toml, .node-version, tools/doctor.sh, docs/ops/toolchain.md.


## Plan

Steps (repo files first, installs after; the builder records every command and the final doctor output in `## Build`):
1. Add `tools/toolchain.json`: `{"$comment": "<bump rule>", "tools": {...}}` with keys in this order: `rustup {required: true}`, `rust {channel: "1.99.1", targets: ["wasm32-unknown-unknown"], components: ["rustfmt", "clippy"]}`, `node {major: 22}`, `pnpm {version: "12.16.1"}`, `wasm-bindgen-cli {version: "0.2.130"}`, `binaryen {major: 133}`, `wasmtime {major: 50}`, `opentofu {min: "1.13.0"}`, `awscli {major: 2}`, `playwright {version: "1.64.1", browsers: ["chromium"]}`, `docker {required: true}`. 2. Add `rust-toolchain.toml`: `[toolchain]` with `channel = "1.99.1"`, `components = ["rustfmt", "clippy"]`, `targets = ["wasm32-unknown-unknown"]`, `profile = "minimal"`; one key per line, double quotes (the doctor reads the three pinned keys by regex: Apple's /usr/bin/python3 is 3.9, no tomllib).
3. Add `.node-version`: `22` and a newline.
4. Add `tools/doctor.sh` (chmod +x), built like `tools/monitor/log.sh`: a bash-3.2-safe wrapper that resolves the repo root from `${BASH_SOURCE[0]}` and does `exec python3 - "$ROOT" "$@"` into an embedded standard-library program (python >= 3.9). Options: `--root <dir>` or env `BRIDLE_ROOT` (where toolchain.json, rust-toolchain.toml and .node-version are read). Output, plain text: a header; one row per `tools` key `name | want | have | ok|MISSING|MISMATCH`; two file rows `rust-toolchain.toml` and `.node-version` with `ok|DRIFT <field> want X have Y`; last line `doctor: N ok, M failed: <names>`; exit 0 only when every row is ok. Each probe is `subprocess.run(..., timeout=3)` (macOS has no `timeout` binary), run in a thread pool so the whole run stays under 5 s. Probes: rustup `rustup --version`; rust: `rustup toolchain list` must list the channel before anything else runs (the rustc proxy would otherwise auto-install it), then `rustc +1.99.1 --version`, `cargo +1.99.1 --version`, `rustup target list --installed --toolchain 1.99.1`, `rustup component list --installed --toolchain 1.99.1` (`rustfmt-`, `clippy-` prefixes); node `node --version` major; pnpm `pnpm --version` exact with env `COREPACK_ENABLE_NETWORK=0`; wasm-bindgen-cli `wasm-bindgen --version` exact; binaryen `wasm-opt --version` major; wasmtime `wasmtime --version` major; opentofu `tofu version` first line >= min; awscli `aws --version` major of `aws-cli/X`; docker `docker info --format '{{.ServerVersion}}'` (exit 0 within 3 s, else MISSING with the hint `open -a OrbStack`); playwright `npx --no playwright@1.64.1 --version` exact, plus `npx --no playwright@1.64.1 install --dry-run chromium` where every `Install location:` line must name a directory containing `INSTALLATION_COMPLETE` (wording verified in Playwright 1.64.1 `src/cli/installActions.ts`; `--no` because npx assumes `--yes` and installs when stdin is not a TTY).
