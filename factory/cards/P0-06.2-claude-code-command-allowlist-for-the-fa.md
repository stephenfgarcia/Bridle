# P0-06.2 Claude Code command allowlist for the factory

## Spec

What: add the factory's permission allowlist to `.claude/settings.json`. The file already exists (committed by the monitor v4 card P0-10, commit 126d1f8) and carries three hooks (PostToolUse, PostToolUseFailure, SubagentStop) that must stay exactly as they are; this card merges a `permissions` object into it, nothing else.
Acceptance criteria:
1. `.claude/settings.json` is valid JSON with `permissions.allow` entries for: `Bash(cargo *)`, `Bash(rustup *)`, `Bash(pnpm *)`, `Bash(corepack *)`, `Bash(node *)`, `Bash(npx playwright *)`, `Bash(docker *)`, `Bash(docker compose *)`, `Bash(git add *)`, `Bash(git commit *)`, `Bash(git push *)`, `Bash(git rebase *)`, `Bash(git worktree *)`, `Bash(git switch *)`, `Bash(gh pr *)`, `Bash(tofu fmt *)`, `Bash(tofu validate *)`, `Bash(tofu plan *)`, `Bash(tools/monitor/*)`, `Bash(python3 tools/monitor/*)`, `Bash(bash tools/doctor.sh)`; and `permissions.deny` for `Bash(tofu apply *)`, `Bash(tofu destroy *)`, `Bash(aws *)` (no carve-out: deny always wins in Claude Code, so credential checks run inside scripts such as tools/doctor.sh or by the user), `Bash(git push --force*)`, `Bash(git push -f *)`, `Bash(git push * --force*)`, `Bash(git push * -f*)`, `Read(.env.local)`, `Read(.env.*.local)`. ## Plan

Syntax verified 2026-11-03 against code.claude.com/docs/en/permissions and /settings: a rule is `Tool(specifier)`; in a Bash rule `*` matches any text, and the space-separated trailing form (`Bash(cargo *)`, which also matches a bare `cargo`) is the documented one (`:*` is an equivalent suffix); `Bash(git push --force*)` has no space, so it also matches `--force-with-lease`. "Rules are evaluated in order: deny, then ask, then allow. The first match in that order determines the outcome, and rule specificity doesn't change the order. A broad deny rule like `Bash(aws *)` blocks every matching call, including calls that also match a narrower allow rule". A bare `Read(.env.local)` is relative to the session's working directory and, as a deny, matches at any depth (gitignore semantics), including `cat`/`head`/`sed` and redirections in Bash. `permissions.allow` lists merge across the user, project and local files; a deny in any file wins; project allow rules apply only in a trusted workspace; Claude Code reloads the file on save.

```python
"""P0-06.2: merge a `permissions` object into .claude/settings.json by text insertion.

Run from the repository root:  python3 -I <path>/merge-permissions.py
Standard library only; not committed (its text is recorded in the card's ## Build section).
The hooks lines are copied byte for byte: the only change to an existing line is `  }` -> `  },`.
Aborts, writing nothing, if the file is missing, does not parse, has duplicate keys, already has
a `permissions` key, or holds anything but a `hooks` key. The result is validated in memory, then
written to .claude/settings.json.tmp and moved over the original with os.replace (atomic rename:
Claude Code reloads settings on save and must never see a half-written file).
"""
import json
import os
import shutil
import sys

PATH = ".claude/settings.json"
PERMISSIONS = {
    "allow": [
        "Bash(cargo *)",
        "Bash(rustup *)",
        "Bash(pnpm *)",
        "Bash(corepack *)",
        "Bash(node *)",
        "Bash(npx playwright *)",
        "Bash(docker *)",
        "Bash(docker compose *)",
        "Bash(git add *)",
        "Bash(git commit *)",
        "Bash(git push *)",
        "Bash(git rebase *)",
        "Bash(git worktree *)",
        "Bash(git switch *)",
        "Bash(gh pr *)",
        "Bash(tofu fmt *)",
        "Bash(tofu validate *)",
        "Bash(tofu plan *)",
        "Bash(tools/monitor/*)",
        "Bash(python3 tools/monitor/*)",
        "Bash(bash tools/doctor.sh)",
    ],
    "deny": [
        "Bash(tofu apply *)",
        "Bash(tofu destroy *)",
        "Bash(aws *)",
        "Bash(git push --force*)",
        "Bash(git push -f *)",
        "Bash(git push * --force*)",
        "Bash(git push * -f*)",
        "Read(.env.local)",
        "Read(.env.*.local)",
    ],
}


def no_duplicate_keys(pairs):
    out = {}
    for key, value in pairs:
        if key in out:
            raise ValueError("duplicate key: %s" % key)
        out[key] = value
    return out


def main():
    if not os.path.isfile(PATH):
        sys.exit("abort: %s not found; run from the repository root" % PATH)
    with open(PATH, encoding="utf-8") as f:
        text = f.read()
    try:
        old = json.loads(text, object_pairs_hook=no_duplicate_keys)
    except ValueError as e:
        sys.exit("abort: %s does not parse (%s); nothing written" % (PATH, e))
    if "permissions" in old:
        sys.exit("abort: %s already has a permissions key; nothing written" % PATH)
    if list(old) != ["hooks"]:
        sys.exit("abort: expected only a hooks key, found %s; nothing written" % list(old))

    body = text.rstrip()
    if not body.endswith("}"):
        sys.exit("abort: %s does not end with }; nothing written" % PATH)
    block = json.dumps(PERMISSIONS, indent=2).replace("\n", "\n  ")
    new_text = body[:-1].rstrip() + ',\n  "permissions": ' + block + "\n}\n"

    new = json.loads(new_text, object_pairs_hook=no_duplicate_keys)
    assert new["hooks"] == old["hooks"], "hooks changed"
    assert list(new) == ["hooks", "permissions"], list(new)
    assert new["permissions"] == PERMISSIONS, "permissions differ from PERMISSIONS"
    old_lines, new_lines = body.splitlines(), new_text.splitlines()
    assert old_lines[-1] == "}" and old_lines[-2] == "  }", old_lines[-2:]
    assert new_lines[: len(old_lines) - 1] == old_lines[:-2] + ["  },"], "existing lines not byte-identical"

    tmp = PATH + ".tmp"
    with open(tmp, "w", encoding="utf-8") as f:
        f.write(new_text)
        f.flush()
        os.fsync(f.fileno())
    shutil.copymode(PATH, tmp)
    os.replace(tmp, PATH)
    print("merged %s: %d allow, %d deny; %d lines -> %d lines" % (
        PATH, len(PERMISSIONS["allow"]), len(PERMISSIONS["deny"]), len(old_lines), len(new_lines)))


if __name__ == "__main__":
    main()
```
