# P0-08.1 Card tooling: manual gates and worktree-safe card.py and log.sh

## Spec

What: the card tool learns manual gates and works from a lane's worktree. Why: the P0-08 row (`docs/plan/roadmap.md` E2 and E1): "`manualGates:` in the card frontmatter; the foreman refuses ship while any is unticked", and "absolute-path card.py and log.sh" so that agents in a worktree report to one place.
Acceptance criteria:
1. Manual gates: a card may list gates in its frontmatter (`manualGates:`); each gate is open or ticked, with who ticked it and when recorded in the card. `card.py move <id> ship` (any status) exits non-zero and names every open gate, and moves nothing; with every gate ticked it moves as today. A command ticks a gate (`card.py gate <id> <gate> --by <who> [--evidence <path or url>]`), and `card.py list` shows the count of open gates of a card that has any. A card without gates behaves exactly as before (the existing tests of `tools/monitor/test/card.test.py` pass unchanged).
2. Worktree-safe: run by absolute path from a linked git worktree of this repository, `tools/monitor/card.py` reads and writes the card files of that worktree (its branch), and `tools/monitor/card.py` and `tools/monitor/log.sh` write their events and traces to `.bridle/progress` of the main checkout, never into the worktree. Run from the main checkout, both behave as today. The rule for finding the main checkout is stated in the files' headers and in `factory/README.md` in one sentence.
3. `card.py new --estimate`: a test holds that the value reaches the card's frontmatter and the printed `tasks/<id>` op.
4. Tests in `tools/monitor/test/card.test.py` (and a shell or python case that creates a real linked worktree in a temporary clone) cover criteria 1 to 3, each with a failing-case assertion; `pnpm check` stays 7/7.
Files: `tools/monitor/card.py`, `tools/monitor/log.sh`, `tools/monitor/test/card.test.py` (and one new test file if the worktree case needs it), `factory/README.md` (one sentence), `.claude/skills/factory/SKILL.md` only if a command's usage line changes.
Test command for `## Test`: `python3 tools/monitor/test/card.test.py` (plus the worktree test file if one is added, named in `## Test`).

Out of scope for every P0-08 sub-card: product code (`apps`, `packages`, `crates`), `tools/agent-hq/`, and the monitor's page and viewer beyond what an acceptance criterion names. Process notes from 2026-11-17 that apply here: an absolute claim ("every", "all", "none", "only") in a shipped document or comment needs a test or a command that holds it; a station's verdict is FAIL only for an unmet acceptance criterion, a failing command, a false statement in a shipped file or a real defect, and everything else is an advisory; negative proofs and experiments run in a scratch copy or behind a backup checked with `cmp`.
