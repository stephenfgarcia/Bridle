# P0-11 Resume-ability: the plan, a root README, progress and decisions logs in the repository

## Spec

What: make the repository self-describing, so that a person or a fresh Claude session can open it after a break and learn, from committed files alone, what Bridle is, what the plan is, what has shipped, what is in flight, what is next, which decisions the owner made and what only the owner can do. Today the approved plan lives only in `~/.claude/plans/` on one machine, there is no root README, several owner decisions exist only in chat, and the progress record is spread over 70 cards and the monitor.

Why: the user's instruction of 2026-11-03 ("prioritize this so that we will not hallucinate"): a session that cannot find the state will invent it. The committed copy becomes the canonical plan; every later amendment is a commit.
