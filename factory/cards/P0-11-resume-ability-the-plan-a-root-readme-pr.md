# P0-11 Resume-ability: the plan, a root README, progress and decisions logs in the repository

## Spec

### Risks and how to check them
- Verbatim copy: the roadmap source lacks a final newline, so a byte-for-byte `cmp` against the raw source fails by one byte; the check compares against the source plus one newline (step 1), and the test pins 371/109 body lines, the H1 and the last line. Any later amendment to the plan changes those pins on purpose, in the same commit.
- Stale board: every `card.py move` (P0-02.4 ships alongside; this card's own moves) makes `--check` fail until `--write` runs. The tester regenerates the board if a card moved under it and says so in `## Test`; the foreman regenerates at every commit that touches a card (line.md rule). CI's `code` job skips docs-only commits, so a cards-only commit is checked locally only; `pnpm check` on the next code commit catches it.
- Ship ordering: the hash is unknown before the ship commit, so the log entry is appended before the commit and the hash filled in right after, with `## Ship` (step 9); the board is regenerated twice (before the ship commit and after the move to ship).
- Portability: docs.test.sh runs on macOS bash 3.2 and ubuntu bash 5 (python3 3.12 on the runner): basic regex only, `grep -o`, `cut -d'|'`, no `mapfile`, no `sed -i`, no `grep -P`; the plan-copies external diff is skipped on CI by design.
- E2 parsing assumes 4 cells per row and ids in the first cell (true for all 52 rows today); a future title containing `|` shifts cells and the test fails loudly with the row.
- README links resolve locally even for untracked files; the builder checks every named path with `git ls-files` (step 7).
- Biome: `biome.json` excludes docs, factory, .claude and tools/monitor, and Markdown and shell are not Biome languages, so `pnpm lint` is unaffected; verify with the `pnpm check` run.
- serve.py loads card.py through importlib: keep module-level code free of new side effects and keep `parse`/`task_doc` unchanged; serve.test.py proves it.
- The decisions log: an entry without a located source is left out (the Spec's rule); the keyword list of the `decisions` case names only the sourced entries above.
- The two monitor-owner constraints (no event from `status`, nothing under `.bridle/progress/`): card.test.py's `test_no_side_effects` and the reviewer's grep for `log.sh`/`.bridle` in the `status` code path.
