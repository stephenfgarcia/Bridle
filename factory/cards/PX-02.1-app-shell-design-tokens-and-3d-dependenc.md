# PX-02.1 App shell, design tokens and 3D dependencies

## Spec

Pitch card W1 of `docs/plan/pitch-plan.md` (web lane; apps/web), approved by the owner with the plan on 2026-11-18. What: Dependencies (three.js, react-three-fiber, a state store), design tokens, app shell and navigation. Why: the showcase of 2026-12-16 for the owner's pitch and thesis defense on 2027-01-01. Review station: no (the pitch process: one agent builds and tests; `pnpm check` green before the commit). The foreman writes this card's acceptance criteria here before its build starts.

Acceptance criteria (foreman, 2026-11-18):
1. `apps/web` gains the dependencies the workspace needs: `three`, `@react-three/fiber` and `@react-three/drei` in versions that support React 19 (the builder checks the published peer ranges and pins exact versions, as the other dependencies are pinned), and `zustand`; `pnpm install --frozen-lockfile` and `pnpm check` pass with them.
2. Design tokens: the custom properties of `docs/ux/tokens.css` are available to the app from one stylesheet under `apps/web/src`; a test fails when that stylesheet and `docs/ux/tokens.css` differ, or the app imports the file directly, whichever is simpler, stated in the Build section.
3. App shell: a top bar with the product name and a navigation with the entries Workspace and Tasks; the route `/workspace` renders the shell with an empty viewport area and a side panel area, laid out for a laptop screen of 1280 by 720 and larger; the route `/tasks` renders the shell with a "coming soon" state; `/` keeps working and links to `/workspace`. Light theme only.
4. Every user-facing string is in the catalog of `packages/i18n` and `pnpm lint` (the string lint) passes.
5. A minimal 3D proof inside the viewport area is allowed but not required; if present it is one static grid, with no interaction (W2 builds the viewport).
6. Tests: `pnpm e2e:smoke` still passes, extended by one check that `/workspace` shows the navigation; `pnpm check` is 7/7. `tools/test/web.test.sh` has a case named `plain` that fails on any stylesheet, `components` directory, `<nav` or `<header` in `apps/web`: this card removes or rewrites that case so that the file passes, and says so in the Build section.
Files: `apps/web/`, `e2e/`, `packages/i18n/messages/`, `pnpm-lock.yaml`, `tools/test/web.test.sh`. Out of scope: the 3D viewport's behaviour (W2), the model store (W3), sign-in, dark theme, mobile layout.
